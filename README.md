# Regina Artesanatos

Site responsivo desenvolvido para apresentar produtos artesanais e itens de decoração de forma moderna, organizada e acessível.

## Sobre o projeto

O projeto Regina Artesanatos foi criado para divulgar produtos voltados à decoração e organização da casa.

A proposta é oferecer uma experiência visual agradável, permitindo que os visitantes conheçam os produtos e entrem em contato com a responsável pelo negócio.

O projeto continua em desenvolvimento e receberá novas funcionalidades.

## Funcionalidades

- Apresentação da marca
- Exibição de produtos em cards
- Navegação pelas diferentes seções da página
- Layout adaptado para diferentes tamanhos de tela
- Área de contato
- Interface moderna e organizada

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages
